# Place Hibermachy in Super+Space

Type: prototype
Status: resolved

## Question

Where should Hibermachy appear in Quattro's Super+Space menu so configuration and immediate actions feel native without cluttering the root menu?

## Answer

Use the prototype's Variant A:

- Add **Sleep & Hibernation** beneath **Setup**; selecting it summons Hibermachy's Quickshell settings panel.
- Add **Suspend then Hibernate** beneath **System**, alongside the existing Suspend and Hibernate actions.
- Do not add a dedicated Hibermachy row to the root menu.
- Make the nested entries searchable by sleep-, hibernate-, and Hibermachy-related terms.

Prototype context: branch `prototype/super-space-menu`, commit `b324179`, file `prototypes/super-space-menu/index.html`.

## Comments

The user selected Variant A after comparing three interactive information architectures.
