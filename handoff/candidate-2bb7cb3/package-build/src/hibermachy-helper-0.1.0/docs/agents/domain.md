# Domain docs

Hibermachy is a single-context repository.

## Before exploring

- Read the root `CONTEXT.md` for the project glossary.
- Read relevant ADRs under `docs/adr/` when they exist.
- Proceed silently when an ADR directory or a relevant ADR is absent.

## Use the glossary

Use the exact terms defined in `CONTEXT.md` in issue titles, specifications, interfaces, tests, diagnostics, and user-facing copy. Avoid synonyms the glossary explicitly rejects.

When a needed concept is absent, reconsider whether it is project language or record the gap for domain-modeling rather than silently inventing a competing term.

Surface any conflict with an existing ADR explicitly before changing the design.
